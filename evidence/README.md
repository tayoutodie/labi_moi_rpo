# Фактические проверки в доступной Linux-среде

Эти журналы записаны при реальном запуске программ в **временном Linux-контейнере**, не на компьютере студента.

- [linux-smoke.log](linux-smoke.log) — сборка и запуск C/Python для лабораторных 1–3, исправленного примера №9 с ASan/UBSan.
- [linux-observations.log](linux-observations.log) — PID/PPID, код 7 у дочернего процесса, CPU, обычные потоки Python, VmSize/VmRSS и библиотеки.

**Ограничения:** нет GUI/скриншотов System Monitor и VS Code, GDB и strace недоступны, Python 3.14t недоступен; эксперимент с 80 MiB и сокращённый потоковый замер являются вспомогательными проверками, а не заменой полного задания преподавателя. Зафиксированные PID и метрики относятся только к контейнеру. Оригинальные бланки `labs/*/report.md` оставлены для заполнения по собственным измерениям, без вымышленных данных.
