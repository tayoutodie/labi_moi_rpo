
# sysprog-start

Мои работы по дисциплине «Системное программирование»: лабораторные работы, исходный код на C и Python, отчёты, домашние задания и материалы курса.

| Информация | Данные |
|---|---|
| Автор | Северинов Константин Сергеевич |
| Группа | 9/2-РПО-24/1 |
| Курс | 2026/2027 |
| Операционная система | Windows 11 |
| Языки программирования | C, Python |
| Редактор | Visual Studio Code |

## Лучшие работы

| Работа | Что сделано |
|---|---|
| [ЛР 1 — Процесс изнутри](labs/01-process-inside/) | Изучение процесса, PID, памяти и системных характеристик |
| [ЛР 2 — Отладчик](labs/02-debugger/) | Отладка программы, анализ стека вызовов и инструкций |
| [ЛР 3 — Библиотеки](labs/03-libraries/) | Анализ загруженных DLL и динамических библиотек |
| [ЛР 7 — Потоки Python](labs/07-python-threads/) | Изучение потоков и поведения CPU |
| [ЛР 8 — Карта памяти](labs/08-memory-map/) | Исследование использования памяти процессом |
| [ЛР 9 — Ошибки памяти](labs/09-crash/) | Анализ ошибок памяти и способов их обнаружения |

В репозитории собраны исходные файлы и отчёты по девяти лабораторным работам. Степень выполнения каждой работы и подтверждающие материалы указаны в соответствующих папках `labs/`.

Автоматические проверки GitHub Actions не заменяют реальные измерения и скриншоты, полученные во время выполнения лабораторных работ.
