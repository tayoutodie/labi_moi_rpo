# Системное программирование — лабораторные №1–9

Материалы организованы по [официальному шаблону курса](https://github.com/MaximBytecamp/sysprog-start-template): девять отдельных папок в [labs/](labs/README.md), задания, бланки отчётов и исходные программы.

## Что подготовлено

- Исходники на C и Python для лабораторных 1–3, дополнительные воспроизводимые диагностические программы для 4–6, исходный код шаблона для 7–9 и исправленный вариант для 9.
- VS Code GDB configuration для работы 2.
- Скрипт локальных smoke-проверок `bash scripts/check_linux.sh`.
- [Фактические результаты тестов](evidence/README.md) в Linux-контейнере.

## Статус выполнения

**Программная часть частично проверена**, но лабораторные **не готовы к полной сдаче**: в оригинальных бланках `labs/*/report.md` остались поля о локальном оборудовании, наблюдениях, GDB/strace, Python 3.14t и требования к реальным скриншотам. Не следует представлять контейнерные замеры как результаты на личном компьютере.

## Проверка

```bash
bash scripts/check_linux.sh
```

Для экспериментов с умышленными ошибками памяти используйте изолированную тестовую среду.
