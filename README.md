# Системное программирование — лабораторные работы 1–9

Работы по структуре [шаблона преподавателя](https://github.com/MaximBytecamp/sysprog-start-template). Каждая работа оформляется в своей папке `labs/NN-*` с `README.md`, `report.md` и, когда требуется, исходным кодом.

**Статус:** программная часть подготовлена частично; практические наблюдения, измерения и реальные скриншоты ещё нужны. Не выдавайте шаблонные отчёты за завершённые измерения.

[Содержание всех девяти работ](labs/README.md).
